# P05 — metadata, ingestion and optimization

Owner: Codex. Scope: P05 only; starting from completed P04, with its external
deployment exceptions unchanged. Workspace is initially untracked; preserve it.

1. Inspect frozen raster/statistics, SQLite transactions, pattern and CLI tests.
   Retain oracle captures for full, sampled and chunked metadata and optimization.
2. Extend the shared GDAL boundary with native statistics/geometry and raster
   preparation; preserve linear whole-image percentiles and chunked t-digest.
3. Add transactional create/insert/delete/overwrite and coordinated lazy loading;
   preserve SQLite encoding and cross-language rollback/read/write behavior.
4. Implement ingestion, raster-pattern/RGB ordering, serve-from-pattern, and
   optimization flags including memory/disk, masks, codecs and overviews.
5. Run differential metadata/geometry, database/concurrency, actual CLI and COG
   image checks; reuse the full WorldCover source for chunking/disk optimization.
   Repair failures, run relevant rendering regressions and Rust checks.
6. Retain reproducible evidence, update discoveries/decisions/coverage/status and
   leave a handoff with exact commands and any remaining qualification gaps.

Acceptance: frozen Python can read and modify Rust databases and vice versa;
failed transactions roll back; concurrent lazy requests publish one consistent
metadata result; full/sample/chunk statistics preserve their algorithm and masks;
optimized output passes the frozen COG validator and visible-render comparisons;
real ingest/serve workflows and skip/overwrite/error flags work. Synthetic inputs
are limited to constant/all-invalid and similarly isolated edge semantics.
