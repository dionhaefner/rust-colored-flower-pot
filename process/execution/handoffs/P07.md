## Decisions and compatibility details

Read D-009/D-010 and RW-032–038 before changing integration behavior. In
particular: computed percentiles retain binary64 while stored blobs remain
float32; raw whole-raster reads use densified transformed source bounds; Python
futures use spawn and transfer settings; public contexts yield SQLAlchemy
connections, pin remote generations and retain per-operation commit behavior.
`DataStore.batch` is separately atomic. Native profile/debug flags have documented
operational alternatives, not an interactive Python debugger. A timeout or
disconnect does not forcibly cancel GDAL.

The remote socket emulator proves native transport and lifecycle behavior, not
real AWS credentials. boto's in-process mock and mutable private cache internals
cannot be used as tests of the native S3 transport. Do not hide that exclusion or
reintroduce Python networking merely to make those mocks intercept Rust.
