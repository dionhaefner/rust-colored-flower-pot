## Implemented

- Native restricted Python-expression parser and bounded postfix evaluator,
  supported operators/functions/constants, Python precedence, masked values,
  NumPy dtype promotion/unsigned overflow and invalid-operation semantics.
- All 171 built-in palettes, categorical colors and custom uint8 NPY maps with
  Fortran layout, name overrides and live replacement. Gamma, forward/inverse
  sigmoidal and LCH saturation preserve channel-local hidden mask values.
- Compute tiles/previews, remaining singleband/RGB options, discovery/filter/
  sorting/paging, metadata batch/columns/limits, error/method/CORS contracts,
  exact frozen API specification/documentation/static assets and client version.
- Shared `Application::request_full` carries body and headers through native
  HTTP, C ABI, Python/WSGI and Lambda v1/v2. Existing four-item Python request
  result and prior native request entry remain supported.
- Raster read/warp settings, alpha and valid-zero semantics, sparse/empty tiles,
  nonsquare fallback and high-zoom handling. Process-lifetime GDAL library handle
  prevents TLS-destructor crashes when application worker pools are recreated.
- Retained notices for color-operations 0.4.0 and ReDoc; bundle includes them.

Main implementation files: `src/expressions.rs`, `src/color.rs`, `src/palettes.rs`,
`src/http.rs`, `src/raster.rs`, `src/storage.rs`, `src/ffi.rs`, `src/lambda.rs`,
Python adapters and `src/assets`. D-006 records the shared boundary/assets/parser
choices. RW-016–020 document discoveries, preserved quirks and repaired failures.
