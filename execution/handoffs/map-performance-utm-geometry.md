# Handoff: UTM suggested-geometry cache reuse

Date: 2026-09-28. Scoped local optimization complete; packaged release artifacts remain unchanged.

The UTM fast path previously recomputed GDAL's source-wide suggested warp geometry on every band/tile, despite the worker-owned `SourceEntry.suggested` cache already used by the general path. [src/raster.rs](../../src/raster.rs) now owns `cached_suggested_geometry()`, called by both the general path and [src/raster/utm.rs](../../src/raster/utm.rs). Source size and modification time identify the local dataset generation; remote datasets are not cached. No changed image or API behavior is intended.

[Alternating direct Rust A/B](../../validation/evidence/p08/map10-utm-geometry/ab-summary.json): three trials, same original UTM COGs, three CPU cores/workers and 160 MiB aggregate logical cache. All 412 decoded RGBA URLs match the previous Rust binary. Eight-user RGB pan p50 falls 79.57→52.23 ms (1.52×), four-user RGB 30.20→22.70 ms (1.33×); single-user RGB is 6.85→8.29 ms and has no supported improvement claim. A three-trial [Python requalification](../../validation/evidence/p08/map10-utm-geometry/summary.json) yields 23.09× eight-user RGB median pan gain (55.01 ms Rust versus 1,269.95 ms Python), and all 18 paired trial ratios exceed 10×. Strict Python image hashes still differ under accepted RW-046; masks and bounded differences are unchanged. Six sampled overview/edge fallback outputs match Python exactly.

Current binary SHA-256: `3fa0b076f977a62a97e6247aa64bb0a64aecbe6356971f26c59a7cc861536ba5`. The prior binary `f7843c2fffb16db78c13bac677870d578eca83a040be81ad5276487fdc83effc` is preserved at ignored `validation/artifacts/map10-utm-final/terracotta-baseline` for local A/B reproduction. Keep the previous [UTM report](../../validation/evidence/p08/map10-utm/README.md) as historical baseline. One-trial two/six-worker probes were worse than three for loaded RGB; no worker-count change. Rust fmt, strict Clippy, 20 unit tests and exact fallback checks pass. [Full follow-up evidence and commands](../../validation/evidence/p08/map10-utm-geometry/README.md).

Remaining candidate improvements require distinct evidence: reuse projection coordinates across aligned RGB bands, avoid repeated decoded-block loads on simultaneous misses, or cache final encoded tiles under a bounded invalidation policy. These have not been measured or implemented. Measure them before claiming gains, especially for first-view and tail latency. No cloud, container or publishing work occurred.
