# P03 handoff

Task / phase / owner: P03 / Codex, completed 2026-09-22.

Outcome: the Linux x86_64 executable now ships as a relocatable GDAL/PROJ/codec
bundle and no distributable path discovers the reference virtualenv. A clean
Debian container reads SQLite and the pinned real Sentinel-2 raster offline and
returns an exact decoded image. Required upstream/Rasterio notices are retained.

The same bounded `Application::request` core now serves native HTTP, API Gateway
v1/v2 events, the custom Lambda Runtime API, a minimal CPython extension, and a
WSGI adapter. Python `render_preview` returns PNG bytes; native startup failures
become `RuntimeError`, and HTTP render failures become `TerracottaError`. The
minimal P03 database operation copies one already-computed record using the
legacy schema/coordinate/float32 encoding and refuses to replace a destination;
it is feasibility evidence, not the complete P05 writer.

Packaging: `packaging/build-bundle.sh` produces the 66,761,789-byte host bundle.
`build-python.sh` creates an importable CPython 3.12 Linux package with the
native runtime. `build-lambda-target.sh` compiles inside the digest-pinned
official `provided.al2023` image; `build-lambda.sh` produces a 26,055,524-byte
x86_64 zip (SHA-256
`ab12fd06b877f0a6243c2886059176c5a3fcd729b7b6a71127be29b088efc4ae`).
The final Lambda binary requires at most glibc 2.34 and bundles AL2023
expat/libgcc/libstdc++/zlib plus notices. The host-build ABI failure and fix are
RW-015; D-005 records the adapter/package choice. RW-003 identities and RW-012
runtime discovery are advanced/resolved for the qualified targets.

Validation: see `validation/evidence/p03/README.md`. The local suite passed
21/21 import, return/error, WSGI, API Gateway v1/v2, fake Runtime API, package,
identity, and Python↔Rust database checks. All extension/WSGI/Lambda images were
exact after RGBA decoding; the retained native-scale sheet was visually
inspected with no difference. The clean Debian container and pinned official
AL2023 runtime-image smokes both rendered exact real-raster output with runtime
network disabled. P01 passed 26/26 exact regressions; P02 passed all eight RGB
cases plus range/cache/concurrency. Offline corpus/comparator checks, 14 Rust
tests, locked build, and Clippy `-D warnings` pass.

Limitations: this is intentionally not full Python/Flask/WSGI compatibility;
those methods/types/settings/scripts remain P07. The one-record SQLite write is
not the transactional P05 API. No actual AWS Lambda function was created or
invoked because cloud deployment/spend was not authorized; local event protocol,
bootstrap, target ABI, native library loading and official runtime-image
execution are proven, but service IAM/network/cold-start behavior is not.
Linux/arm64, Lambda arm64, macOS and Windows are untested. P02's real S3/custom
endpoint and physical BigTIFF gaps remain unchanged.

failed first image was removed. No process or container is active.
