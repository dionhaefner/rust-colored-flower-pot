# P02 execution plan

Owner: Codex; assigned scope: P02 only. Started 2026-09-22.

Prerequisites inspected: P01 is complete and its 26-case exact differential and
full-parent stress evidence are retained. The frozen Python source/environment,
Python-created SQLite database, seven real-raster subsets, and full 36,000 ×
36,000 WorldCover COG are available. The repository remains an intentionally
uncommitted initial tree, with no active process or overlapping P02 work.

1. Put GDAL reads behind a bounded worker-owned execution pool with a bounded
   admission queue, unique VRT identities, explicit overload and wait-timeout
   results, failure recovery, and resource/cache metrics. Keep timed-out native
   work accounted for until it actually completes.
2. Add a bounded raster cache whose identity includes source identity, bounds,
   dimensions, categorical behavior, and local file generation. Add RGB
   preview/tile routing, per-channel numeric/percentile stretches, repeated-band
   de-duplication, legacy black transparency, and partial-mask behavior.
3. Support GDAL `/vsicurl/` and `/vsis3/` raster paths and startup-only GDAL/S3
   environment configuration without logging credentials. Preserve ordinary
   local paths and P01 results.
4. Extend the validation harness with exact Python/Rust RGB comparisons,
   partial-mask and repeated-band cases, local/range-served equivalence, cache
   isolation/hits, bounded overload/timeout/failure recovery, cold/warm
   concurrency, remote request/byte accounting, handles, RSS, and full-parent
   overview/detail remote reads.
5. Run focused tests, P01 regressions, locked offline build/test/Clippy, and the
   P02 fast/stress suites. Repair failures, inspect the retained visual sheet,
   then update evidence, coverage, discoveries/decisions, README/status, and a
   resumable handoff.

Acceptance: all locally executable P02 exits in `execution/PHASES.md` have
retained evidence. Real S3 credentials/custom endpoints and physical
multi-GiB/BigTIFF offsets remain explicit external/data gaps if unavailable;
local HTTP ranges do not clear those checks. Request wait timeout is documented
as a response bound, not cancellation of GDAL work.

Completed 2026-09-22. All locally executable acceptance items passed; real S3/
custom endpoint credentials were unavailable and the retained corpus has no
physical multi-GiB BigTIFF. See `execution/handoffs/P02.md` and
